# Nurshia Launcher

Windows ve Linux için ücretsiz Minecraft: Java Edition launcher'ı. Bu depoda sadece kurulum
dosyaları var. Tanıtım ve gizlilik politikası: https://nurshia.com/launcher

## İndir

[Son sürüm](../../releases/latest) sayfasından:

- **Windows:** `Nurshia.Launcher_x.y.z_x64-setup.exe`
- **Linux:** `Nurshia.Launcher_x.y.z_amd64.AppImage` (çalıştırılabilir yapıp aç). `.deb` ve `.rpm` de var.

Launcher kendini günceller; yeni sürüm çıkınca açılışta haber verir.

Windows ilk açılışta "Windows bilgisayarınızı korudu" diyebilir: uygulama ücretli bir kod
imzası sertifikasıyla imzalı değil. **Ek bilgi → Yine de çalıştır** ile açılır.
